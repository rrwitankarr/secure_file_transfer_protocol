# Secure File Transfer Protocol (SFTP)

A Python-based secure file transfer system that enables encrypted communication and secure file exchange between client and server.

---

## Features

- Secure file transmission
- Encrypted communication using RSA keys
- File upload and transfer handling
- Server logging functionality
- Support for multiple file types
- Simple client-server architecture

---

## Technologies Used

- Python
- Socket Programming
- RSA Encryption
- SFTP Concepts
